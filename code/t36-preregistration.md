# T36 · 条件精排（跨语言 / 低置信）预注册

> 写于看条件精排结果之前。跑后不改闸门、不做阈值择优。  
> 对照基线：T35 的 `mode=bm25 --title-weight 4`（同语料同 query）。

## 动机

T35 全量精排全面落后：高置信中文词法命中被语义重排打散。本轮只在两类场景启用精排。

## 闸门（先定）

| 闸门 | 规则（不看答案） | 预期触发 |
|---|---|---|
| **xlang** | query **不含汉字**（纯 ASCII 表面启发式） | Q13–Q16 |
| **lowconf** | query **含汉字**，且 BM25 榜首 chunk 分 **`< 15`** | 弱分中文（如口语/换述里 top1 偏低者）；高分精确术语不进 |

阈值 15：来自同语料 BM25 top1 分位观察——强命中簇多在 ≥16.8，弱分/未命中多在 ≤12.9；写死后不改。

组合：

1. `--rerank-gate xlang`
2. `--rerank-gate lowconf`
3. `--rerank-gate xlang,lowconf`

其余同 T35：`topn=50`、`rerank-doc-chars=512`、模型 `jina-reranker-v2-base-multilingual`。

## 判定（跑前写死）

相对 T35 BM25（@1 0.6923 / @5 0.8077 / MRR 0.7355）：

- **取胜**：文件级 @1 严格更高，且 MRR 不低于基线。
- **非劣**：@1 持平，且 @5 或 MRR 严格更高。
- **未胜**：其余（含 @1 持平但深度指标也未升）。

另表：只报告被闸门命中的子集上，相对 BM25 的名次变化（升/降/不变），**不**单独改总判定。
